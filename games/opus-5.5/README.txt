OPUS 5.5 game collection

How to play
1. Download and extract the entire ZIP.
2. Open START-HERE.html in desktop Google Chrome or Microsoft Edge.
3. Pick a game. You can also double-click any of the three game HTML files.

No installation, account, local server, or internet connection is required.
Three.js and the required add-ons are embedded in each game HTML file.
Use a keyboard and mouse. Mobile play has not been tested.
Click inside the game to activate controls and audio. Esc releases the mouse.
Use the game's controls/settings menus for key bindings and graphics options.
These are unofficial, experimental AI-generated game recreations, with possible bugs.

Troubleshooting
- Extract the ZIP first; don't launch games from the ZIP preview.
- If HTML opens in a text editor, use Open with > Chrome or Edge.
- If graphics fail, enable browser graphics acceleration and restart the browser.
- Large worlds may take time to load. Lower the in-game graphics settings if needed.
- Saved settings/progress use this device's browser storage where supported.
  Browser privacy settings, clearing browser data, or moving the HTML file can affect saves.
