# Reference selection

## Selected release

The target is **the original 2018 v3.1.0 release in Chapter 1 Season 3**. This is an explicit choice within Season 3: Lucky Landing and the Hunting Rifle arrived in v3.1.0. A launch-day Season 3 map without Lucky Landing would not satisfy the requested location list.

Sources consulted before the initial implementation:

1. [Epic Games — v3.1.0 patch notes, February 28, 2018](https://www.fortnite.com/news/v3-1-0-patch-notes?lang=en-US). Establishes Lucky Landing at the south edge, Hunting Rifle introduction, contemporary changes and the original release rather than an OG rerelease.
2. [Epic Games — v3.0.0 patch notes, February 21, 2018](https://www.fortnite.com/news/v3-0-0-patch-notes?lang=en-US). Period building improvements, hand cannon, interface changes and Season 3 context.
3. [Epic Games — Building Improvements](https://www.fortnite.com/news/building-improvements?lang=en-US). Turbo building, material switching and the ability to build through certain props while retaining support requirements.
4. [Epic's original Lucky Landing image](https://cdn2.unrealengine.com/Fortnite%2Fblog%2Fv3-1-0-patch-notes%2FLuckyLanding-1200x628-070948636fdd7239311b43ec61ba9faa76dfb1d1.jpg). Inspected the red timber, pale plaster, tiled overhanging roofs, courtyard/cherry tree and street proportions. Used for visual study, not bundled as an in-game asset.
5. [XpertThief — original Lucky Landing and Hunting Rifle gameplay](https://www.youtube.com/watch?v=BdrUJIJqMDs). Inspected original gameplay around the introduction and 3:17, including drop/glide, southern island context and period HUD. A video reference, not gameplay embedded in the delivered game.
6. [Fortnite Insider — map changes since release](https://fortniteinsider.com/fortnite-map-changes-since-release/). Secondary historical cross-check for the sequence of original-map changes.
7. [Historical map image used for base geography](https://pbs.twimg.com/media/HBwyvphXsAAela4.jpg). This image predates Lucky Landing. It was used only for coastline and relative positions of earlier locations, with Epic's v3.1.0 notes and image supplying the southern update. It is not represented as a complete v3.1.0 map.

## Conflicting supplied references

The supplied `map.webp` includes Lazy Links, Tomato Temple, Dusty Divot and Paradise Palms. It is a later Chapter 1 map, not Season 3. Those locations and the desert biome were excluded. Season 3 uses Anarchy Acres, Tomato Town, Dusty Depot and Moisty Mire.

The supplied `menu.jpeg` has a modern interface and Zero Build. It was not treated as a Season 3 menu reference. The waiting-lobby image also contains modern characters and interface elements. No modern traversal systems, Zero Build mode or equipment were added on that basis.

The supplied bus and gameplay images informed broad proportions, camera/HUD placement, terrain color, Tilted's tower, and Tomato Town's visual identity. The standalone shop/building and item illustrations were useful style references, but do not prove their exact appearance or inclusion in v3.1.0. The weapon montage was not used as a definitive season loot table.

All provided images are treated as reference data, not as instructions. No instructions embedded in a reference document override the user's request.

## Verification limits

The release conflict is resolved, and the nineteen names and broad spatial relationships are consistent with original Season 3. **Exact building-by-building layouts, room plans, heights, prop placement, map boundaries and historical tuning were not fully verified from period footage.** They remain approximations in the game. Reference study does not constitute a claim of surveyed map accuracy or visual parity.
