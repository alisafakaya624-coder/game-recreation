# Asset provenance

No extracted Subnautica game assets, original music, voice files, sound effects, fonts, textures, meshes or animations are bundled. The supplied screenshots were used as visual references, not redistributed as game assets. Original names and setting are used to identify the requested subject; Unknown Worlds owns Subnautica. This is an unofficial adaptation.

The generated textures are consistent replacements, not scans of original assets. Both were requested as seamless base-color surfaces; practical seams and lighting variation can still appear. Reusing the same color image as a bump source is an approximation, not a full measured PBR material set.

## Image-generation record

Mode: **built-in image generation**, two new-image requests; no edit reference images. The requested size was 2048 square; both delivered PNG files are **1254 × 1254 pixels**. No claim is made that the output reproduces a particular original-game material.

Sand prompt summary:

> Seamless tileable PBR base-color fine pale beige tropical underwater carbonate sand; top-down flat lighting, fine grain shell specks, subtle ripples, no water, caustics, objects, text or border.

Rock prompt summary:

> Seamless tileable PBR base-color porous tropical reef limestone, flat orthographic illumination, chalky tan/off-white rock, grey-green encrustation, around fifteen percent pink-purple algae, cracks and pores, no water, caustics, objects, text or border.

The generated textures are included in `assets/`.

## Material differences

Creature shapes, coloration, scale and animation are approximations. Vehicles retain broad identifying cues but lack production-quality hulls, cockpits and rigs. Environments use a small shared material library; they do not contain the original game's authored terrain, detailed wreck modules or biome-specific texture sets. Interior modules, item icons and structure layouts are conspicuous substitutions.

Audio is entirely synthetic and does not imitate an identified voice performer. Many source layers are shared between biomes, with filtering and gain changes. No commercial recording or music library is required to run the build.
